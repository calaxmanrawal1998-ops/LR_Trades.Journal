🔌 Broker Sync — Live Connect Beta

Connect a broker account to pull closed trades in automatically. Currently supports Tradovate, since it's the only one of the three with a real cloud API. MT5 and NinjaTrader don't expose one — both can export trade history to CSV though, so use the importer above for those.

⚠️ Your Tradovate login is sent straight from this browser to Tradovate's own servers (api.tradovate.com) — nothing passes through a third party. Your password is never stored, only used once to get a session token. If you check "remember," your App ID/CID/Secret are saved in this browser's local storage, so only do that on a device you trust — and use an API key you can revoke from Tradovate's Application Settings any time.
